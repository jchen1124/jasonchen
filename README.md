# jason-chen.dev - v1

A modern, responsive portfolio web app for [Jason Chen Portfolio](https://jason-chen.dev).

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```


## Tech Stack

- React 19 + TypeScript
- Vite
- Material UI, Bootstrap
- Node.js/Express (backend)
